## 2026-11-20 · WS11 Agents hub, Ask PIF upgrade, shared UI (Claude Code)

**Did**
- Live runs: `openai.respondStream` (Responses API `stream: true`, same result shape as `respondRaw`), used by `RunContext.turn` only while someone watches the run. `lib/agents/stream.js` is the in-process hub (replay buffer, decodes the JSON `answer` field as it arrives). `GET /api/agents/runs/:id/stream` (SSE, `Cache-Control: no-transform` so compression doesn't buffer it). `runs.run({ onCreate })` hands back the run id before any model call.
- Ask PIF conversations: `ask_threads` + `ask_messages` (`lib/schema/ask.js`), `lib/agents/askThreads.js`, routes in `routes/agentStream.js` (`/api/ask/threads*`, `/api/ask/agents`). Follow-ups send the last 3 turns as context (numbers from earlier answers don't count as backed). `@slug` asks a team agent: Ask PIF answers with that agent's instructions and tickers (run gets `agentId`, trigger `mention`). Share posts `ask_shared` to the feed and sets `agent_runs.shared`; teammates "continue as your own" (`forkOf`).
- UI: `public/askConversation.js` (one live conversation used by the side panel and Agents → Ask), `public/ui/{agentChip,runCard,feedItem,memoryPill,schedulePill}.js` (`runCard.watchRun` and `mountRunCard` follow a run live with a polling fallback). `public/views/agents.js` is now a shell over the tab registry; tabs in `public/views/agents/` (home, ask, briefs, desk, approvals, activity, events). Feed/Theses/Cockpit links appear in the tab bar once their routes.d entry exists. `#/agents/new` opens WS3's builder tab.
- Home tab (`GET /api/agents-hub/home`): needs you, running now (live), your/followed/team agents, team feed, recent conversations. Command palette: Ask PIF from the box, agents, runs and conversations (`GET /api/agents-hub/search`). Notifications page groups agent notifications by agent with "Mute this agent" (`POST /api/agents-hub/mute`, an `agent_follows` row with notify `none`; `engine.notify` skips those members).
- Tests: `test/agentStream.test.js`, `test/agentStreamApi.test.js`.

**Unfinished**
- No unmute button yet (the API takes `mute: false`); WS7's agent profile page is the natural place.
- Stretch not done: keyboard-first agent console, "Morning brief" view.
- Top nav unchanged (Agents stays one entry; its tab bar carries Feed/Theses/Cockpit).

**Gotchas**
- Streaming is per process (like `lib/events.js`); a second instance would need a shared bus.
- `#/agents/ask?thread=12`: the `?` part arrives inside the `:tab` param; the shell splits it.
- Notification grouping keys on the title prefix (agent name) and a `#/agents/runs/:id` link.
