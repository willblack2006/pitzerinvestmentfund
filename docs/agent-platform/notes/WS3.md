README paragraph for WS12:
**Agent builder.** Agents → Build (or "Create agent" in the Gallery) sets up an agent without code: pick what it watches, when it runs (schedule or events like new filings, big moves, estimate cuts), optional free checks, the steps (read data, apply a rule, or an AI step with instructions), and where results go (team feed, notifications, shared memory, thesis checks). Or describe it in a sentence and the form fills itself in. The side panel says in plain English what the agent will do and roughly what it costs; Test shows when it would have fired over the last 30 or 90 days before you save. Every save is a version you can compare and restore. The Gallery lists templates and the team's agents to use, duplicate or follow.
