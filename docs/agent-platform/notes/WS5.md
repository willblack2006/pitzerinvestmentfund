**README paragraph for WS12**
> Shared memory: the fund's agents and members build one memory (Agents → Memory, or `#/memory`). Agents read what the fund already knows about a ticker before they work, cite memory by id (m12), and add what they learn; an agent's facts and decisions wait for a member's approval, members' notes count right away, and anything can be edited (with history), pinned or retracted. Each ticker gets a nightly "What our agents know" card on its Research page. Agents also hand work to each other on a blackboard (a filing brief hands off to the thesis check; any agent can post a question on a topic) and can ask another team agent directly, and every run's "Why?" panel shows the memory, handoffs and data it used. Tell Ask PIF "remember I care about FCF conversion" to shape your own answers.
